# 剧本制作

剧本改动写在一个 JSON 文件里（纯文本，用记事本或 VS Code 编辑），然后运行：

```bat
python san11kit.py scenario scenarios/我的剧本.json
```

它会把改动编进游戏目录里的剧本文件。改了 JSON 就再运行一次，每次都从干净的原版剧本重新生成，不会越改越乱。
在 `project.json` 的 `scenarios` 里列出的 JSON，`python san11kit.py world` 时会自动编译。

改完要在游戏里**开新游戏**才能看到（存档里保存的是开局时的状态）。

## 最小的例子

在 184 年剧本里加一个只有一座城、一个武将的势力：

```json
{
  "base": 0,
  "forces": [
    {
      "name": "羅馬",
      "cities": [ {"city": "羅馬"} ],
      "officers": [ {"name": "凱撒"} ]
    }
  ]
}
```

完整的例子见 [scenarios/europe_184.json](../scenarios/europe_184.json)。

## 写字一律用繁体

游戏用的是繁体中文的 Big5 编码，所以城市名、武将名、国号都要用繁体字（凱撒、羅馬，不是凯撒、罗马）。
写了简体字，编译器会告诉你是哪个字有问题。

## 查名字和编号

```bat
python san11kit.py cities                 列出全部城市（编号、名字、坐标）
python san11kit.py cities --find 羅       只列名字里有「羅」的城
python san11kit.py forces --base 0        184 年剧本里现在有哪些势力、各几座城
```

## 全部字段

### 剧本本身

| 字段 | 必填 | 说明 |
|---|---|---|
| `base` | 是 | 在哪个原版剧本上改，见下表 |
| `title` | | 剧本标题，最多 8 个汉字 |
| `description` | | 剧本说明，选剧本时显示 |
| `forces` | | 新势力的列表 |

| base | 剧本 | base | 剧本 |
|---|---|---|---|
| 0 | 184 年 黄巾之乱 | 7 | 251 年 英雄集结 |
| 1 | 190 年 反董卓联合军 | 8 | 198 年 吕布讨伐战 |
| 2 | 194 年 群雄割据 | 9 | 203 年 袁家之战 |
| 3 | 200 年 官渡之战 | 10 | 217 年 汉中争夺战 |
| 4 | 207 年 三顾茅庐 | 11 | 187 年 何进包围网 |
| 5 | 211 年 刘备入蜀 | 12 | 191 年 局势掌控者 |
| 6 | 225 年 南蛮征伐 | 13 | 251 年 女流之战 |

### 势力（`forces` 里的每一项）

| 字段 | 必填 | 说明 |
|---|---|---|
| `name` | 是 | 国号，1~2 个字，游戏里显示成「××軍」 |
| `cities` | 是 | 这个势力的城（至少一座），见下 |
| `officers` | | 新武将，见下 |
| `existing_officers` | | 拉进来的原版武将，见下 |
| `ruler` | | 君主的名字（必须是这个势力自己的武将）；不写就用第一个武将 |
| `color` | | 势力颜色编号 0~54；不写就自动选一个别人没用的 |
| `stars`、`intro` | | 选势力画面上的难度星级（1~5）和介绍文字 |
| `relations` | | 和其他势力的友好度，按对方君主的名字写，比如 `{"馬騰": 80, "董卓": 10}`，0~100，默认 50 |

### 城（`cities` 里的每一项）

| 字段 | 必填 | 说明 |
|---|---|---|
| `city` | 是 | 城市名（繁体）或编号 |
| `troops`、`gold`、`food` | | 兵力、金、粮，默认 10000、2000、30000 |

只能占这个剧本里**无主**的城。新增的几百座城一开始全都无主；光荣的城在不同剧本里有的有主有的没有，用 `forces` 命令查。

一个剧本最多能有多少个势力，由 `project.json` 的 `forces` 决定（默认 42，最多 249 且不超过城市数，见[地图与城市](地图与城市.md)）。
`intro` 介绍文字只对编号 0~41 的势力有效。

### 新武将（`officers` 里的每一项）

| 字段 | 必填 | 说明 |
|---|---|---|
| `name` | 是 | 名字。单姓自动拆成姓+名；复姓（諸葛、司馬、夏侯……）也能自动识别，或者用 `sei`、`mei` 分开写 |
| `city` | | 在哪座城（必须是这个势力的城），默认第一座 |
| `stats` | | 能力：`[统率, 武力, 智力, 政治, 魅力]`，每项 1~120，默认都是 60 |
| `apt` | | 兵种适性：`[枪, 戟, 弩, 骑, 兵器, 水军]`，0=C、1=B、2=A、3=S，默认都是 B |
| `face` | | 头像编号（游戏自带的头像）。不写会轮流用几张异族的头像 |
| `sex` | | 0 男、1 女 |
| `birth`、`death` | | 生年、卒年，默认 150、240 |
| `loyalty` | | 忠诚，默认 100 |

一个剧本最多 30 个新武将：光荣在武将表里只留了这么多空位。要更多人，可以用下面的办法拉原版武将。

### 拉原版武将（`existing_officers` 里的每一项）

| 字段 | 必填 | 说明 |
|---|---|---|
| `name` | 是 | 原版武将的名字（繁体，和游戏里一样） |
| `city` | | 在哪座城，默认势力的第一座城 |

只能拉在这个剧本里「在野」「未登场」「未发现」的武将，已经属于别的势力的不行。

## 常见错误

| 编译器说 | 怎么办 |
|---|---|
| 「×」不在繁体 Big5 字库里 | 改用繁体字 |
| 城市「×」在这个剧本里已经有主人了 | 换一座无主的城，或换一个 base 剧本 |
| 找不到城市「×」 | 用 `san11kit.py cities --find` 查准确的名字 |
| 新武将的空位用完了 | 一个剧本最多 30 个新武将，多的改用 `existing_officers` |
| 君主「×」必须是它自己的武将 | `ruler` 写的名字要出现在这个势力的 `officers` 或 `existing_officers` 里 |

## 进阶

编译器的源码是 `tools/scenario_build.py`，开头有剧本文件每个字段的字节位置。想做 JSON 还不支持的改动
（比如改原版武将的能力、改城市的兵装），可以照着里面的写法加几行 Python。剧本文件的完整格式见根目录的
`COORDS.md` 第 2 节和 `M7_LAYOUT.md` 第 8 节。

## 用名单里的人物建势力（scenario_roster.py）

`scenario_build.py` 在导入扩展武将名单之前运行，新武将只能用光荣留的 30 个空位。要用名单（`data/persons/roster.json`，
一万三千多位真实人物）里的人组成几十个势力，用 `tools/scenario_roster.py`，它在 `import_roster.py` **之后**运行：

```bat
python tools/import_roster.py <数据目录>/scenario/Scen008.s11 imp/Scen008.s11
python tools/scenario_roster.py scenarios/world_198.json --data <数据目录> --in imp/Scen008.s11 --out <数据目录>/scenario/Scen008.s11 --report r.json
```

`--in` 是导入名单后的文件（不改它），所以 JSON 改了重新运行即可。例子：`scenarios/world_198.json`（198 年 呂布討伐戰，base 8）、
`scenarios/world_194.json`（194 年 群雄割據，base 2）。这两份 JSON 由 `scenarios/gen/` 里的脚本生成（`python scenarios/gen/w198.py scenarios/world_198.json`，`python scenarios/gen/w194.py scenarios/world_194.json scenarios/world_198.json`），要改先改脚本；按 198/194 年的史实给欧洲、西亚、北非、
东非、印度、中亚、草原、西域的政权配城和武将；光荣的中国部分不动。

和 `scenario_build` 的 JSON 相同的字段：`base`、`forces`、`name`、`ruler`、`cities`（城名，或 `{"city", "troops", "gold", "food"}`）、
`color`、`stars`、`intro`、`relations`。不同之处：

| 字段 | 说明 |
|---|---|
| `officers` | `{"p": 名字, "city": 城}`。`p` 按名单的外文原名 `name_orig`、中文全名 `name_full`、姓+名依次查找（名单重建时编号会变，所以不用编号）；同名多人加 `"born": 大约生年`。也可以 `{"koei": "趙雲"}` 拉光荣原版的未登场/未发现/在野武将 |
| `birth` | （武将项里）名单生年明显不对（剧本那年还没出生或不到 14 岁）时改用的生年；名单登场年晚于剧本年的，登场年自动改成剧本年。所有改动记在 `--report` 里 |
| `auto` | 自动收人：`{"polity": [...], "roles": [...], "min_conf": "B", "exclude": [...]}`：名单里属于这些政权、身份、可信度够、剧本那年 16~75 岁、出身/活动城是本势力的城的人，都在那座城当武将 |
| `kokugo` / `kokugo_name` | `false` 表示不设国号（游戏里像光荣的群雄一样用君主名称呼）；`kokugo_name` 是国号（1~2 字），默认用 `name` |
| `strategist` | 军师（本势力武将的 `p`） |
| `max_cities` | 城数上限，超过就报错 |
| relations 的键 | 本 JSON 里的势力名，或光荣原有势力的君主名（如 `曹操`） |
| 剧本的 `tiers` | 按城的档次（`1`/`2`/`3`/`koei`）给默认兵、金、粮，默认 25000/5000/50000、12000/3000/25000、5000/1500/10000 |

限制：国号空位 42 个（用完后不设国号）；颜色 55 种（用完后挑离得最远的势力的颜色）；势力介绍只有 0~41 号势力有。
工具写完后检查：君主在自己的城、每个武将的城属于他的势力、城和军团一致、不在世的人和已有归属的人不能用、
人物记录里只有登场/生年/所属/状态/忠诚/功绩几个字节变、其它段落不变。
