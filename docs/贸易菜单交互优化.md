# 贸易菜单交互优化（2026-11-08）

本次保留城市「贸易」逐级展开、原版一览窗口、数字键盘和商品图片，调整操作顺序与返回规则。经济参数、商才 20% 正毛利奖励、商队名额及存档格式沿用既有规则。

## 操作流程

| 场景 | 调整后的操作 |
|---|---|
| 手动组队 | 推荐商路或自选目的地 → 调整货单 → 确认出发 |
| 修改组合货物 | 在同一商品列表点商品 → 直接输入数量；0 移除，返回保留货单 |
| 推荐配货 | 先保留原货单再替换；可用「恢复原货单」撤回最近一次推荐 |
| 自动贸易 | 船型、预算、优先目标、偏好商品 → 可选试算 → 保存 |
| 偏好商品 | 使用原版多选框连续勾选；决定提交，返回取消本次多选；全不选表示系统配货 |
| 自动目标 | 可选「不限，系统择优」，解除原先的优先目标 |
| 到港处理 | 管理页直接接管 → 卖货 → 买回程货物 → 返回出资城或续航 |
| 多种货物出售 | 勾选商品 → 查看合计和逐项毛利 → 一次确认成交 |
| 市场发现商路 | 商品 → 各地行情 → 选择开放市场，带入目的地和商品进入组队页 |

原版单选列表本来就是点行即进入下一步，本次减少的是中间操作菜单和成功提示，并未另加一层「决定」。

## 返回、保存与反馈

- 组队和自动贸易有未提交修改时，返回提供「保留草稿」「放弃修改」「继续编辑」。草稿按势力和城市隔离，只在本次运行中保留；读档、新游戏或退出游戏会清除，不写入存档。
- 自动贸易的「仅保存设置」保留所选启用/暂停状态，不立即调度；「保存并启用本城」将本城计划启用并立即评估新派遣。后者不调度其他城市，也不触发已有商队的到港交易。两者均保留本月占用金额及派遣记录。
- 暂停新派遣不会停止已出发商队的自动往返；接管一支商队也不会暂停该城整个计划。
- 买卖后留在商品列表，可连续操作。成功或失败显示在原版底部说明区；输入、货单不会因失败被清空。出发、交易、接管和结束行程仍有必要的确认。
- 反复进入的配货、买卖、管理、商队列表保留行顺序及滚动位置。原生表头的排序箭头不作为存档内容保存。
- 商队管理默认只看本城出资的商队，可切换全势力；初次进入时先列需处理和已停靠商队。
- 「待处理」只列异常或商人已回收的自动商队。自动管理期间的手动买卖、改道等操作置灰，并在同一管理页提供接管入口。
- 船型选择和续航确认显示本城实际费用，包含已生效的商才折扣；自动设置显示本城是否具备商才。

## 批量出售边界

1. 默认勾选单项预估不亏损的货物；亏损商品需要自行勾选，并在最终确认中明确提示。
2. 每种商品按市场可接收的数量出售，仓库放不下的余货保留；不能接收的行置灰。
3. 提交前统一验证商品、数量、仓容、自动管理状态和合计报价。重复商品、超售或报价变化会整笔拒绝，尚不扣货。
4. 合计报价按实际顺序计算税额尾数、旧欠税、进货成本及商才奖励；单项列表估算与最终合计可能因欠税和尾数分配略有不同，以最终确认为准。
5. 一笔批量交易使用提交时的商人等级，全部成交后结算经验，避免首项成交升级改变后续项目价格。后续交易使用升级后的等级。
6. 使用已有收入、税收、待入账和货物账本，不另造一套资金系统；已售货物不能再次提交获得收入。
