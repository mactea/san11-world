# 城市通过附近港口开展海运

日期：2026-11-08。状态：后台实现和测试通过，2026-11-08 21:39 已部署到正式游戏；未进行本次原生港口出航实机验收。

## 规则

- 城中心 3 格内有河流或海面：继续采用原有近岸直航，不增加接驳费或接驳时间。
- 不满足直航条件：在原游戏的 35 座港口中，寻找与该市场城市同势力、陆路可达且接驳路径不超过 20 格的港口。选择最短接驳距离，等距按港口编号确定。
- 起点港口必须与出资城同势力；外地目的市场使用该市场所属势力的港口。不能借用敌方、盟友或无主港口绕过归属限制。
- 接驳陆路按六角格搜索，不穿越河海、悬崖、关卡或其他城市。水上航路仍须通过原生寻路和全程水面校验；有港口不等于任意两城之间都有可航行航路。
- 接驳是抽象货运，没有新增独立陆运单位。商船在港口集结，等待货物接驳完成后出航；到达对方港口后，也需完成港口至城市的交付等待。港口周围已有的短距离下水规则保持不变，入水后不能跨陆。

## 时间、收费和预算

每一端按实际接驳路径计费：每格 2 金；每 10 格 1 旬，分别向上取整。两端直航则为零。

单程支付 = 货款 + 原有组建费或续航费 + 起点接驳费 + 终点接驳费。

两端接驳费在该段出发时一次收取，计入费用账本；到港不重复扣款。商才仍按已有规则减免组建／续航费，接驳费不再折扣。正常海上航行、兵粮消耗、税费和货损仍使用现有规则。

自动贸易的选货和收益计算包含接驳成本；出发时预留返程续航费及返程两端接驳费。回程配货只支付续航费，不重新支付组建费。接驳失败后等待恢复，不因重复下令或读档重复收费。

在途重试相同目的地保留原定港口，不重新收取出发费用；主动改往其他市场按新行程收费，已执行行程的费用不退款。

## 操作和异常

- 城市原生贸易菜单的组队页和确认页显示两端港口位置、接驳距离、时间和费用。
- 商队列表增加“接驳”状态，详情显示等待方向与剩余旬数；续航、返回出资城的确认金额包含接驳费。
- 接驳未完成时禁止出售、采购、续航；商队仍是地图部队，临时商人的隐藏和回收规则不变。
- 港口失守、同势力条件消失或接驳陆路中断时暂停交付。货物仍在商队库存中，不凭旧缓存继续结算。条件恢复后可继续完成接驳；自动贸易已有异常决策与重试规则仍生效。
- 陆路接驳目前核对固定地形连通性，不模拟单独货车、沿途部队拦截或每格领土通行税。港口附近的商队仍受游戏部队规则影响。
- 优先直航，其次选择最近可接驳港口；当前没有“手动选择港口”或按整条海路遍历所有备选港口的功能。若所选港口与目的地的水路不连通，出发失败并沿用原有退款流程。
