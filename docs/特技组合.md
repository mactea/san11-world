# 特技组合

worldmod 可以把多个原版特技的效果组合成一个编号。武将仍然只有一个特技字段，剧本和存档的字段长度不变。

## 启用

编译 `worldmod/build.bat`，通过工具包正常部署 DLL。部署会在游戏目录缺少 `worldmod_skills.txt` 时复制示例配置；更新时保留已有配置。

在游戏目录的 `worldmod.ini` 中，为需要启用的启动程序添加：

```ini
[san11pk_world]
skill_combos=1
```

默认关闭。`[mod] verify_only=1` 时会检查配置和补丁指令，但不会安装组合特技补丁。

## 定义组合

编辑游戏目录里的 `worldmod_skills.txt`，保存为 **UTF-8**。每行格式是：

```text
编号|名称|说明|组成效果编号，以英文逗号分隔
```

例如随附配置：

```text
100|明略|虛實、名聲、發明|57,79,82
101|神膽|遁走、騎將、強行、長驅、洞察|1,37,2,3,61
102|清談|機智、名聲、論客|55,79,86
108|仁德|伯樂、遁走、眼力、名聲|146,1,85,79
```

- 新组合编号为 **100～249**。名称必须填写，组成效果必须有 1～8 项，每项可以使用原版 **0～99** 编号，以及已实现的 **146 伯乐**。
- 可以定义原版 0～99 编号，为它追加效果；它自己的原版效果始终保留。
- 不支持嵌套组合。已实现 146 伯乐的跨城登用效果（相性差不超过 25）；其它 SIRE 扩展效果没有移植，不能作为组成项。未使用的这些编号在 worldmod 中可以用作自定义组合编号，两套配置不通用。
- 名称、说明用游戏 Big5 字库支持的文字（通常用繁体），分别最多 **4、66 个 Big5 字节**，即最多 2、33 个汉字。UTF-8 文件会在加载时转换为 Big5；名称遵循原生特技短名字段的长度。
- 不要在字段中使用 `|`，不要给编号加空格。空行和以 `#` 开头的注释行会被忽略。
- 编号重复、效果编号越界、文字无法转换、字段过长等都会拒绝配置，在日志中指出出错行。所有补丁写入前会核对原始指令，防止覆盖其它修改器。

改动后重启游戏生效。配置不会嵌入存档；分享剧本或存档时应一并提供配置。

## 给武将赋予组合

在剧本 JSON 的新武将对象里添加 `skill`：

```json
{"name":"凱撒","city":"敦煌","skill":100}
```

这只是字段示例；在现有武将对象中添加 `skill`，保留他的其它设置。然后重新编译剧本：

```powershell
python san11kit.py scenario scenarios/europe_184.json
```

新开局会读取修改后的剧本；已有存档不随剧本修改。已有存档中的武将如果已经持有该编号，重启后会按新的组合定义判定效果。255（文件）/ -1（内存）仍表示无特技。

本版本通过剧本中的编号赋予新组合，**没有扩展原生编辑器的特技下拉菜单或研究树**。原生特技总数和原版数据序列化保持不变；已经赋予的新组合通过资料查询接口提供名称、说明和编号。类别、等级沿用第一个组成效果的原版资料，不能单独配置。

各原版效果仍遵循自己的触发条件。例如把骑将、发明组合到一起，不会让骑将对所有兵种生效；没有另外添加 SIRE 的兵种匹配规则、宝物附加特技或伯乐的月初推荐事件。

## 实现与验证

`worldmod/src/skills.cpp` 负责配置、Big5 转换及十处补丁：武将判定、赋值、部队判定、资料查询、资料地址转编号、排序顺序、武将列表排序字段、特技字段读写、收入类特技汇总和伯乐跨城登用筛选。部队判定沿用原生的成员查找，不依赖固定武将数组或 1099 上限。

收入汇总单独展开原版组成效果，补齐富豪、米道、征收、征税这一条不经过普通武将特技判定的路径。128～249 号的读档修正只作用于武将特技字段，其他有符号字节字段不变。

测试命令（需要 Visual Studio x86 C++ 工具和本地支持版本的原版 exe）：

```powershell
worldmod/tests/run_skills_tests.bat "C:/San11PK/san11pk.exe"
```

测试从 exe 读取实际指令，在独立进程的代码缓冲区验证并执行补丁分支，覆盖配置错误、组合与无特技判定、超出 1099 的武将编号、名称/编号查询、排序、收入汇总和 128～249 的字段往返。底层流 I/O 和收入列表遍历使用桩函数；这些测试不等同于完整游戏界面及完整存档文件的端到端测试。
