# 城市贸易入口（2026-11-01）

目标：在城市命令菜单追加原版样式的「貿易」，保留全部原命令。

静态确认并经隔离游戏验证的接口（san11pk_world.exe）：

| 接口 | 地址 / ABI | 用途 |
|---|---|---|
| 城市菜单虚表 | `0x851d00` | 对象 `+0x354` 为当前建筑指针 |
| 创建命令列表 | `vt+0x1e8 = 0x617790`，thiscall，无参数，返回 int | 先调用原函数，再追加贸易项 |
| 原版 AddItem | `0x59f4b0`，thiscall `(label CP950, itemId, enabled)` | 原版绘制、布局、命中和悬停，不覆盖原命令 |
| 点击回调 | `vt+0x11c = 0x6186e0`，thiscall `(button*)` | 先查主菜单、再查 `menu+0x1a8` 子菜单的 itemId；仅截获 `0x7001..0x7005`，父项 `0x7000` 由原版展开/收起 |
| 子项范围 | `vt+0x1f0 = 0x617890`，thiscall `(id, first*, last*)` | 贸易父项返回连续五项；叶项返回两个 INT_MIN |
| 文字 / 可用性 / 帮助 / 父项 | `vt+0x1fc / +0x204 / +0x20c / +0x210` | 分别为 `0x617ab0 / 0x617ae0 / 0x617b80 / 0x617a00`；新增 id 用自有映射，其他 id 委托原函数 |
| 显示/隐藏 | `vt+0x4c`，thiscall `(visible)` | 模态期间分别隐藏父菜单和内嵌子菜单，返回后恢复可见状态，保留展开层级 |
| 大地图中地图入口 | `0x61d1c0`，thiscall，无参数 | 主界面为 `*(*(0x91ba018)+8)`；原函数管理模态生命周期 |
| MapUI 主地图模式 | `0x63d500`，thiscall `(mainMap)` | 设置 `+0x8c`；原 Init 的第一次 compose 发生在它之前 |

首次按钮消失的关键条件：`panelForce` 要求 MapUI `+0x8c == 1`，首次 compose 时该标志尚未设置。模式设置后重新 compose/layout，且覆盖层直接接收正在合成的 MapUI。选择据点模式仍不绘制贸易面板。

入口仅在 `trade=1`、贸易 UI 及世界中地图安装成功时挂接；按建筑 id 和玩家所有权过滤，点击时再次检查。安装前核对全部七个虚表槽和模式设置函数原始字节，不匹配则记录错误并跳过该入口。

实机证据位于 `worldmod/build/trade-game/city-menu-*.png`：初次中地图按钮、我方城市新增按钮、自动带入小沛、组队页、返回恢复、原「都市」子菜单、子菜单打开时再次进入贸易。没有执行交易或推进回合，前后完整贸易 dump 相同。此记录不替代贸易经济、拆合队或多站航行的专项验收。

后续两级菜单实测见同目录 `submenu-*.png`：五个叶项分别打开市场、组队、商队、账本、消息页；返回后仍展开；切换军事子菜单、切回贸易及再次点击收起均正常。运行日志记录五次 action 1..5，贸易 dump 前后相同。`trade_runtime_test` 新增菜单范围、旧菜单委托、叶项边界、页面路由、账本状态及旧组队确认清理的回归用例。

## 内层原生窗口

城市入口已改为 `trade_dialogs.inc` 的原生操作流程；中地图入口作为地图辅助保留。适配器 `trade_native_ui.h` 不改全局列表虚表，只复制到本次模态的上下文，退出并销毁窗口后释放。文字使用 CP950，绘制、键盘、鼠标、滚动和按钮均由原游戏负责。

| 接口 | 地址 / ABI |
|---|---|
| 一览窗口构造 / 析构 | `0x64cf20 / 0x64cfb0`，thiscall，无参数；对象 `0x2cc` 字节 |
| 窗口虚表 | `0x85b9e0`，共 `0x1e8` 字节；覆盖 `+0x1d8` 列表工厂、`+0x1e4` 列组描述 |
| 窗口参数初始化 / 创建 | `0x4ae240 / 0x64e1d0`；参数 `0x144` 字节，标题 `+0xc`、最少选择 `+0x18`、最多选择 `+0x1c` |
| 模态 | `0x64cb20`；决定返回 `10000`，取消不提交 |
| 基础列表构造 / 创建 | `0x4e47c0 / 0x4e5770`；对象 `0x1ac`，虚表 `0x8344f8` 共 `0x200` 字节 |
| 列表数据回调 | `+0x19c` 列数、`+0x1a0` 表头、`+0x1a4` 列宽、`+0x1ac` 排序方式、`+0x1e0` 单元格文本、`+0x1fc` 排序值 |
| 添加 / 读取行 | `0x4e6340(index, keyLo, keyHi)` / `0x4e5070(index)`；行记录为 64 位键、可用标志 `+8`、选中标志 `+0xc` |
| 数字键盘 | `0x4f2630`，cdecl `(params*)`；参数为标题、最小、最大、初值、禁止取消标志、回调，取消返回 `-1` |

注意：`0x64d650` 返回的是**滚动位置**，不是选中行。必须扫描原生行记录的 `+0xc`，再用该记录的稳定键取业务 ID，不能用屏幕行号。原版单选模式（最多选择 1）点选后直接返回；只读模式（0）仅有返回。确认明细采用原版决定／返回双按钮，列表禁止选择，点击明细本身不会提交。

已在隔离副本验证原版样式、数字输入、单选、逐级返回、取消不修改贸易数据，以及实际组队、买入、卖出、结束与结果反馈。证据：`nativeui-*.png`、`nativeui-before.txt`、`nativeui-after-cancel.txt`、`nativeui-after-send.txt`、`nativeui-after-transactions.txt`、`nativeui-operations.log`。正式存档不用于交易测试。
