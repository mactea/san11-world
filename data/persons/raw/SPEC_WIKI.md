# 英文维基百科人物条目 → 三国志11 武将（子代理用）

输入是从英文维基百科转储里按分类筛出来的人：在世时间与公元 170–370 年可能有交集、不是中国（汉、三国、晋、十六国）人物，
也不在已收的名人库里。每行（用「 | 」分隔）：

`序号 | 条目名 | Wikidata 编号 | 生年（或范围） | 卒年（或范围） | 中日韩维基条目名 | LEGEND（分类里有传说、神话字样） | 分类 | 信息框 | 导言`

## 任务
把每行做成三国志11 武将资料。依据是给出的导言、信息框、分类，加上你对此人的了解。
**导言里没有、你也不确知的事不要编**；资料太少就写短列传，`"known": false`。

**要 skip 的**（写原因，其他字段可空）：
* 不是真实的个人：神话、传说人物（只见于传说、学界认为不存在）、虚构人物、群体、家族、民族、船、建筑、作品；
  圣徒传里学界认为不是真实人物的（如只有传说的殉道者）也 skip；
* 活动时间完全在 170–370 年之外（例如 160 年死、380 年以后才出生或出仕）；
* 中国人（含匈奴、鲜卑等中国北方民族）——中文史书另有来源；
* 同一批里重复的条目；
* 地图以外地区的人：地图覆盖欧洲、北非、阿克苏姆/库施/撒哈拉、中东、高加索、伊朗、中亚、印度（天竺）、东南亚（南海）、
  朝鲜半岛（东夷）、日本（倭）、草原和西伯利亚；**美洲、撒哈拉以南（阿克苏姆、库施以外）的非洲、大洋洲的人 skip**。
拿不准是否真实存在的历史人物（只见于一种晚出史料）：收，但 `"known": false`。

## 输出
写到指定的 JSONL 文件（UTF-8，一行一个 JSON 对象），**每个输入行一条**（按序号），字段同 `raw/SPEC_GLOBAL.md`，另加 `title`：

```
{"i": 12, "title": "Fabius Cilo", "qid": "Q123",  // 序号、条目名、Wikidata 编号（照抄，"-" 写 ""）
 "skip": "", "zh": "奇洛", "sei": "奇", "mei": "洛", "zh_full": "盧修斯·法比烏斯·奇洛",
 "sex": "m", "birth": null, "death": 212, "death_violent": false,
 "polity": "羅馬帝國", "role": "文臣", "place": "羅馬", "lat": 41.9, "lon": 12.5,
 "offices": ["城市長官"], "kin": [{"rel": "子", "name": "..."}], "friends": [], "foes": [],
 "bio": "……", "stats": [55, 40, 60, 68, 55], "lean": "無", "known": true}
```

* zh：有中文维基条目名（输入里 `zh:`）就以它为准（转繁体，取游戏名 2~4 字，完整的写进 zh_full）；
  朝鲜、日本人物写汉字姓名（输入里 `ja:` `ko:` 条目名或你知道的汉字写法）。
* 其余规则（译名、Big5、五维尺度、字段含义）完全照 `raw/SPEC_GLOBAL.md`，先读它。
* bio 繁体中文 40~150 字，以导言内容为主。

## 注意
* 每行都要有输出，skip 的也写一行。写完检查 JSON 合法、zh 能 Big5 编码（cp950）、sei+mei==zh。
* 最后回复只报：条数、skip 条数、known=false 条数、文件路径。
