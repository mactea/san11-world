# 从希腊、拉丁史书原文抽取人物（子代理用）

目的：给三国志11 扩展武将名单（公元 170–370 年）从罗马时代史书里列出**原文中出现、有具体事迹的真实人物**。
原文是希腊文、拉丁文或英译本（希罗狄安、《罗马君王传》、优西比乌《教会史》、佐西默斯、阿米阿努斯·马塞利努斯），
块首一行写着书名和卷/章范围，正文里的「[Book N]」「[Vita: …]」是卷、传记的标记，「[N]」是章。

## 收谁
* 收：活动时间与 **公元 170–370 年** 有交集的具体个人——皇帝、皇族、皇后、将领、总督、官员、元老、禁卫军长官、
  篡位者、主教、殉道者、学者、哲学家，以及波斯、亚美尼亚、哥特、阿勒曼尼、法兰克、萨尔马提亚等外族的君主、王子、将领。
* 不收：只被提到的古人（亚历山大、奥古斯都、西塞罗、使徒）；没有名字的人；群体；神话人物；
  370 年以后才开始活动的人；**《罗马君王传》里学界认为是作者虚构的人物**（后半部各传、「三十僭主」里伪造的书信、
  演说、元老院决议中出现的人名多属此类）——你确知是虚构的不收，拿不准的收，但写 `"conf": "C"`。
* 只出现一两次但有具体动作（被任命、出征、被杀、叛变、殉道……）的人也收。
* **已经收过的人不要再收**：`data/persons/_cache/known_world.tsv` 是已有的海外人物（英文名 | 中文名 | 完整中文名 | 生年 | 卒年 | 所属），
  用 Grep 查（按姓、名的英文或拉丁写法）。是同一个人就跳过；但亲属、敌友里提到他们时，用表里的英文名。

## 输出
写到指定的 JSONL 文件（UTF-8，一行一个 JSON 对象，不要 Markdown 代码块），字段：

 "zh_full": "盧修斯·法比烏斯·奇洛",      // 完整中文译名（繁体）

 "polity": "羅馬帝國",                   // 羅馬帝國、薩珊波斯、帕提亞、亞美尼亞、帕爾米拉、哥特、阿勒曼尼、法蘭克、

 "place": "羅馬",                        // 主要活动地（繁体中文地名）

 "offices": ["城市長官", "執政官"],       // 原文出现的职位、头衔（繁体）
 "kin": [{"rel": "子", "name": "Caracalla"}],        // 原文写到的父、母、配偶、子女、兄弟姊妹（英文名）
 "friends": ["Septimius Severus"],      // 原文写到的恩主、盟友、亲信（英文名，最多 5 个）

## 译名
* 用中文世界通行的译名（繁体）：皇帝、名人照维基百科中文条目（塞維魯、卡拉卡拉、奧勒良、尤利安、沙普爾二世）。
  不常见的人按通行音译规则译，游戏名取最有辨识度的部分（通常是 cognomen：「奇洛」「普勞提亞努斯」不好就「普勞提」），
  限 4 个汉字。同名不同人允许游戏名相同。
* 每个字都要在 Big5 里，写完自己用 Python 检查：
  `python -c "import json,sys;[json.loads(l)['zh'].encode('cp950') for l in open(sys.argv[1],encoding='utf-8')]" 文件`

## 五维（三国志11 尺度）
吕布武力 100、关羽 97；诸葛亮智力 100；曹操统率 96、政治 94、魅力 96。
* 史书只记一笔的官员、将校：30~60；多次领兵有战功：统率 65~85；以勇力著称：武力 75~90。
* 谋略、政绩、名望见于记载：相应一项 70~90。90 以上只给世界史上公认的一流人物。
* 主教、殉道者、学者：统率武力 10~40。

## 注意
* 一个块读完再写；同一人在块里用不同称呼（全名、cognomen、官职）合并成一条。
* 写完检查 JSON 合法、zh 能 Big5 编码、sei+mei==zh、没有收已在 known_world.tsv 里的人。
* 最后回复只报：写了多少人、跳过的已知人物大约多少、文件路径。
