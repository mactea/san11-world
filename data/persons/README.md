# 扩展武将名单（M10）

14163 人的武将表：光荣原版 0..849 号**不变**，扩展武将 850..14162 共 13313 人（全部是史料里有的人物，不含虚构），
时间为公元 170–370 年（东汉末、三国、西晋、东晋前期、十六国，以及同时期的罗马、安息/萨珊、贵霜、印度、朝鲜、倭等），
地域对应地图上的 530 座城。字段按三国志11 剧本武将记录（152 字节）准备，导入工具（M10 技术侧剧本格式定下后）直接写入。

统计见 `roster_stats.json`，每人一条的完整数据在 `roster.json`，校验结果在 `validate.json`（全部通过）。

* 还没拿到的书：PLRE I（有版权）；Brosset 法译《格鲁吉亚编年史》（1849，公版，但只能在 Google Books 手动下载；估计只能补十几位卡特利早期国王、贵族，决定跳过，伊比利亚现有 22 人）；
  沙普尔一世铭文（ŠKZ）、派库利铭文的人名表（Frye、Humbach–Skjærvø 译本有版权）；Seeck《皇帝与教宗编年》（1919，未找到开放扫描）。
* 史书抽取的五维是按事迹估的（规则见 `raw/SPEC_TEXT.md`），比光荣原版整体略低（平均约 40–50，光荣约 55–60）；
  只出现一两笔的小人物，列传也短。
* 年份：来源没写生卒的，从列传、出处里的公元年和年号（`tools/roster/eras.py`）推，再没有就取所属政权存续期的中段。
  连父母子女时，若一方的生年是估的、和另一方对不上，就把估的那方挪到合理位置（父母比子女大 14–60 岁）。
* 特技按光荣原版 0..669 号的规律给：有没有特技看最高能力（光荣原版 <70 几乎没有，80 以上约八成），给哪种特技要求能力
  够得上光荣同特技持有者的下限；只有 1–2 人持有的稀有特技只给一流人物；亲乌、亲羌、亲越、亲蛮只给相应地区的人，
  内助、倾国只给女性，妖术、祈願、米道只给方士、僧道。扩展武将多是能力一般的人，所以持有率约 8%（光荣原版 46%）。
* 死法：来源标了横死，或列传最后写的是被杀、战死、自尽、伏诛、殉道，记为横死。
* 相性：中华三国志给了的照用（和光荣原版重合的 650 多人里相性完全一致），其余按所属政权的基准取；
  互相厌恶又相性几乎相同的，把来源没给相性的一方挪开 8–15。
* `audit.json`（`tools/roster/audit.py` 生成）列出关系、属性、相性、特技、出处里不合理的地方和样例；
  剩下的主要是来源本身的问题：父亲在 170 年以前、名单里没有（约 780 人）、一夫多妻的配偶不对称、来源明确写了的高寿等。
