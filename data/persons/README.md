# 扩展武将名单（M10）

11228 人的武将表：光荣原版 0..849 号**不变**，扩展武将 850..11227 共 10378 人（全部是史料里有的人物，不含虚构），
时间为公元 170–370 年（东汉末、三国、西晋、东晋前期、十六国，以及同时期的罗马、安息/萨珊、贵霜、印度、朝鲜、倭等），
地域对应地图上的 530 座城。字段按三国志11 剧本武将记录（152 字节）准备，导入工具（M10 技术侧剧本格式定下后）直接写入。

统计见 `roster_stats.json`，每人一条的完整数据在 `roster.json`，校验结果在 `validate.json`（全部通过）。

## 结果（2026-10-22）
| 项目 | 人数 |
|---|---|
| 武将表总数 | 11228（光荣 850 + 扩展 10378） |
| 扩展武将 | 10378：中国（含周边民族）约 8600，海外约 1800 |
| 可信度 A / B / C | 2250 / 7677 / 451 |
| 有特技 / 有父或母 / 有配偶 / 有亲近 / 有厌恶 | 4008 / 1065 / 383 / 4682 / 4212 |
| 女性 | 551 |

* 史料里能找到、有具体事迹的人物，合并去重并排除光荣已有武将后是 10378 人。原先为凑满 15000 人加的 3772 个虚构补位人物（D）
  已经去掉，所以罗斯、北欧、西伯利亚等史料空白的地区现在没有武将，天竺、贵霜、南海、阿拉伯也只剩个位数到几十人。
  要恢复补位可以运行 `python build.py --total 15000 --fiction`。
* 中国人物多数原文没写籍贯，出身城按所属政权落到首都，所以洛阳、建业一带人数偏多。
* 史书抽取的五维是按事迹估的（规则见 `raw/SPEC_TEXT.md`），比光荣原版整体略低；只出现一两笔的小人物，列传也短。

| `giri` `yabou` `kiyou` `seikaku` | 义理 0..4、野望 0..4、起用 0..4、性格 0 小心 1 冷静 2 刚胆 3 莽撞（+126..+129） |
