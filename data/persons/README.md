# 扩展武将名单（M10）

12221 人的武将表：光荣原版 0..849 号**不变**，扩展武将 850..12220 共 11371 人（全部是史料里有的人物，不含虚构），
时间为公元 170–370 年（东汉末、三国、西晋、东晋前期、十六国，以及同时期的罗马、安息/萨珊、贵霜、印度、朝鲜、倭等），
地域对应地图上的 530 座城。字段按三国志11 剧本武将记录（152 字节）准备，导入工具（M10 技术侧剧本格式定下后）直接写入。

统计见 `roster_stats.json`，每人一条的完整数据在 `roster.json`，校验结果在 `validate.json`（全部通过）。

## 结果（2026-10-22）
| 项目 | 人数 |
|---|---|
| 武将表总数 | 12221（光荣 850 + 扩展 11371） |
| 扩展武将 | 11371：中国（含周边民族、朝鲜、倭）约 8750，海外（罗马、波斯、印度等）约 2620 |
| 可信度 A / B / C | 2273 / 8161 / 937 |
| 有特技 / 有父或母 / 有配偶 / 有亲近 / 有厌恶 | 4407 / 1079 / 415 / 5092 / 4468 |
| 女性 | 648 |

* 史料里能找到、有具体事迹的人物，合并去重并排除光荣已有武将后是 11371 人。原先为凑满 15000 人加的虚构补位人物（D）
  已经去掉，罗斯、北欧、西伯利亚等史料空白的地区几乎没有武将。要恢复补位可以运行 `python build.py --total 15000 --fiction`。
* 出身城和依据记在 `city` / `city_basis`。中国人物：籍贯 2842 人，没有籍贯的按官职、列传里的地名定任职地/事迹地 2135 人，
  再按同宗亲属（父子兄弟叔侄，含光荣武将）的籍贯 428 人，民族 150 人；都没有线索的 2291 人放在所属政权的都城
  （多为朝官、宗室、后妃、宦官、僧人），230 人默认洛阳。所以洛阳、建业仍是人数最多的城。
* 海外人物 2026-10-22 第二轮扩充：希腊、拉丁史书原文（希罗狄安、罗马君王传、优西比乌《教会史》、佐西默斯、阿米阿努斯）
  抽出约 620 人，英文维基百科条目（按年代分类筛出、不在名人库里的）约 590 人，《三国史记》新罗、高句丽、百济约 130 人。
  只有一笔记载、或史料可疑（罗马君王传、圣徒传）的标可信度 C。
* 史书抽取的五维是按事迹估的（规则见 `raw/SPEC_TEXT.md`），比光荣原版整体略低；只出现一两笔的小人物，列传也短。

## roster.json 字段
| 字段 | 含义（括号里是光荣记录偏移） |
|---|---|
| `id` | 武将编号，从 850 起连续 |
| `sei` `mei` `azana` | 姓、名、字（繁体，Big5，各 1~2 字；+0 / +5 / +10） |
| `name_full` `name_orig` | 完整姓名（超长的名截成 2 字时保留全名）、外国人的原文名 |
| `sex` | 0 男 1 女（+55） |
| `birth` `appear` `death` | 生年、登场年、卒年（+58 / +56 / +60）；史料没有的按活动年份估计 |
| `death_type` | 0 天寿/病死 1 横死（被杀、战死、自杀）（+62） |
| `city` `city_id` `region` | 出身城（530 城之一）及其编号、地区 |
| `city_basis` | 出身城的依据：籍贯 / 坐标（海外人物的活动地经纬度）/ 任职地/事迹地 / 亲属籍贯 / 民族 / 政权都城 / 默认 / 地区 |
| `home` | 光荣「出身地方」0 幽州 1 冀州 2 青徐 3 兗豫 4 司隸 5 關中 6 涼州 7 揚州 8 荊北 9 荊南 10 益州 11 南中（+123；海外人物统一 11） |
| `polity` `role` `offices` | 所属政权、身份、官职（资料用，不写入记录） |
| `stats` | 统率、武力、智力、政治、魅力（+113） |
| `apt` | 适性 枪 戟 弩 骑 兵器 水军，0..3 = C B A S（+107） |
| `growth` | 能力成长类型 ×5（+118，取同类光荣武将的值） |
| `lean` | 兵种倾向（生成适性、特技用） |
| `skill` `skill_name` | 特技编号 0..99（原版特技；255 = 无）（+124） |
| `giri` `yabou` `kiyou` `seikaku` | 义理 0..4、野望 0..4、起用 0..4、性格 0 小心 1 冷静 2 刚胆 3 莽撞（+126..+129） |

| `aishou` | 相性 0..149（+74），同一政权的人聚在一起（曹操 25、刘备 75、孙权 125……） |

| `father` `mother` `spouse` `sworn` `blood` | 父、母、配偶、义兄弟、血缘（编号；−1 无；可以指向光荣 0..849 号武将）（+65 / +67 / +70 / +72 / +63） |
| `liked` `disliked` | 亲近、厌恶武将，各最多 5 个（+75 / +85） |

数字（人口、人物数等）凡没核实原文的都在 `conf`/`src` 里标明。
